# Synthetic engineering updates

All examples are invented. No private team data or external link is fetched.
`expectations.json` records outcomes for `config/team-update.yaml`.

The vague and unsupported-claim examples pass **structure checks only**. This is intentional.
Add a required semantic rule with evaluator disabled to route them (and other structurally valid
updates) to REVIEW. The checker does not decide whether anyone is lying or whether work is useful.
The long example exceeds the configured size limit. The prompt-injection example still lacks
Next steps; instructions inside it cannot change policy or create an approval action.
